## 多 Mask 视频跟踪 · GPU（推荐）

已部署 RTX 4090 CUDA 版本，不是把 CPU 服务改名。旧单 Mask CPU 动作仍可作为备用。

1. 保存当前帧的所有 Mask，刷新页面。
2. 点击顶部工具栏 **多 Mask 跟踪 · GPU**（Save / Undo / Redo 旁）。
3. 勾选当前帧的 **1–3 个 Mask**。可选择不同类别，也可选择同类别的不同对象。
4. 向后帧数默认 **20**，最多 **50**，点击 **开始 GPU 跟踪**。
5. 检查生成结果，然后点击 **Save**。运行结果不会自动保存。

规则与限制：

- 每个对象保留自己的类别、属性及独立 Group。未分组对象会分别分配 Group；不要让两个不同的起始对象共用一个 Group。
- 同一 Group 在目标帧已有标注时只跳过该对象，不影响同类别的另一个 Group。
- 目标帧若有未分组的同类别 Mask 且位置重叠，会保守跳过；建议把人工纠正的对象与对应传播对象关联到同一 Group。
- 某个对象消失或面积突然变化时会停止该对象，其他对象继续。提示会说明停止位置；此前有效结果仍需人工检查。
- 取消会等待当前帧请求结束并丢弃本轮结果，已有标注不变。
- GPU 与研究任务共享互斥锁；提示 GPU busy 时稍后重试，不会抢占其他实验，也不会偷偷回退成 CPU。
- 短片段实测 3 个对象通过公网传播约 **0.2–0.4 秒/帧**，实际速度受帧尺寸、目标和 GPU 可用性影响，不构成精度保证。
- 这是已标 Mask 的视频传播，不是用标签文字自动识别医学结构。神经、硬膜、遮挡与器械接触区域仍需仔细检查。
- 旧的点提示与全自动预标注服务没有在本次一并迁移到 GPU；本次 GPU 加速的是视频 Mask 传播。
